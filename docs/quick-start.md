# Quick start

1. Download Windeck from the website, or `brew install --cask windeck`, and open it. It lives in the menu bar.
2. Allow **Accessibility** (required): Windeck lists, raises, closes and minimizes windows, and hears its shortcut, through it.
3. Allow **Screen Recording** (optional) for previews, then restart Windeck when asked. Without it, Windeck shows titles alone.
4. Choose a shortcut:
   - **⌥ Tab** (recommended): the system's ⌘Tab keeps switching apps; ⌥Tab switches windows.
   - **⌘ Tab**: Windeck takes ⌘Tab over, as Windows' Alt-Tab works.

Then hold the modifier and press Tab.
