# Smart features

Windeck learns from the windows you switch to, on your Mac only. It never uses a language model and never sends anything anywhere.

- **The first place is never predicted.** One Tab always goes to the window you were in before.
- **The second place is predicted.** Windeck counts which window follows which (within a run) and which app follows which (across runs, decaying with a half-life of three days). When one candidate clearly stands out, it takes the second place and shows a small star. Otherwise the order is plain recency.
- **Search is ranked by habit.** Among matches, the windows and apps you use often and lately come first. A poor match never beats a good one on habit alone.

Both are part of Windeck Pro, and both can be turned off in Settings › Smart. Settings › Smart also shows how the switcher served you: switches today, how often the window was in the first two places, and keys per switch.
